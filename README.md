# CRUD App – Каталог товарів

Простий та функціональний веб-застосунок для управління каталогом товарів.

## Функціонал
* **Create** – додавання нових товарів із перевіркою унікальності ID та валідацією ціни.
* **Read** – відображення списку товарів у вигляді таблиці.
* **Update** – редагування наявних позицій у каталозі.
* **Delete** – вилучення товарів із підтвердженням дії.
* **LocalStorage** – автозбереження стану каталогу в браузері.
* **Sorting** – сортування елементів за назвою та ціною.

## Технології
* HTML5
* CSS3
* JavaScript (ES6)
